## Look-back window

**7 days**[^1]

7-day look-back/observation period, or since admission/entry or reentry if less than 7 days. The manual uses the phrases "7-day observation period" (N0415I1/I2, p. N-8) and "7-day look-back period" (item set instruction, p. N-4) interchangeably for this item set. The document does not state how the window is counted relative to the ARD on these pages.

> **Note:** the manual states more than one time period for this item. See the *Conflicts* section below.

## Coding rules

1. Check Column 1 (Is taking) if the resident is taking any medications by pharmacological classification during the 7-day observation period (or since admission/entry or reentry if less than 7 days).[^4]
2. Check Column 2 (Indication noted) only if Column 1 is checked, and only if there is an indication noted for all medications in the drug class.[^5]
3. Code all high-risk drug class medications according to their pharmacological classification, not how they are being used.[^6]
4. Check N0415I1 if an antiplatelet medication (e.g., aspirin/extended release, dipyridamole, clopidogrel) was taken at any time during the 7-day observation period (or since admission/entry or reentry if less than 7 days).[^1]
5. Check N0415I2 if there is an indication noted for all antiplatelet medications taken at any time during the observation period (or since admission/entry or reentry if less than 7 days).[^2]
6. Code medications in Item N0415 according to the medication's therapeutic category and/or pharmacological classification, not how it is used.[^7]
7. Do not code antiplatelet medications such as aspirin/extended release, dipyridamole, or clopidogrel as N0415E, Anticoagulant.[^8]
8. Medications with more than one therapeutic category and/or pharmacological classification are coded in all categories/classifications assigned to the medication, regardless of how the medication is being used.[^9]
9. Include any of these medications given to the resident by any route in any setting (e.g., at the nursing home, in a hospital emergency room) while a resident of the nursing home.[^10]
10. Code a medication even if it was given only once during the look-back period.[^11]
11. Count long-acting medications given every few weeks or monthly only if they are given during the 7-day look-back period (or since admission/entry or reentry if less than 7 days).[^12]
12. For transdermal patches, capture the medication only if the transdermal patch was applied to the resident's skin during the observation period.[^13]
13. Combination medications should be coded in all categories/pharmacologic classes that constitute the combination.[^14]
14. Herbal and alternative medicine products are dietary supplements and should not be counted as medications.[^15]
15. Check N0415Z1, None of the above, if none of the listed medications (including antiplatelet) were taken by the resident at any time during the observation period (or since admission/entry or reentry if less than 7 days).[^16]

## What the chart must show

1. Medical record documentation that the medication was received by the resident and documentation of the indication for its use during the 7-day look-back period (or since admission/entry or reentry if less than 7 days). *(importance to an auditor: high)*[^17]
   Step 1 of Steps for Assessment for N0415.
2. Documentation from other health care settings where the resident may have received any of these medications while a resident of the nursing home (e.g., valium given in the emergency room) must be reviewed. *(importance to an auditor: medium)*[^18]
   Step 2 of Steps for Assessment for N0415.
3. An "indication" must be the identified, documented clinical rationale for administering the medication, based upon a physician's (or prescriber's) assessment of the resident's condition and therapeutic goals. *(importance to an auditor: high)*[^19]
   Definition box governing Column 2 coding.
4. Assessors should be able to identify the source(s) used to support coding the pharmacological classification on the MDS 3.0; facilities may wish to identify a consistently used resource. *(importance to an auditor: medium)*[^20]
   Framed as a suggestion ("may wish") but with an expectation that the source is identifiable.
5. Providers are responsible for coding each medication's pharmacological/therapeutic classification accurately; use of the listed reference resources is not required for MDS completion. *(importance to an auditor: medium)*[^21]

## ⚠️ Conflicts — please read carefully

> **Terminology of the observation window for N0415I ("7-day observation period" vs. "7-day look-back period")**
>
> - *RAI Manual v1.20.1 (Oct 2025):* N0415I1 states the window as the "7-day observation period (or since admission/entry or reentry if less than 7 days)."[^22]
> - *RAI Manual v1.20.1 (Oct 2025):* The N0415 item form states the window as "during the last 7 days or since admission/entry or reentry if less than 7 days," and other rows in the same list (e.g., N0415H1) use "7-day look-back period."[^23]
>
> Status: Not a substantive difference in length: both describe a 7-day window (or since admission/entry or reentry if shorter). Terminology difference recorded; treated as the same 7-day window.
