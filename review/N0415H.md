## Look-back window

**7 days**[^1]

7-day look-back period ending on the ARD; if the resident has been in the facility less than 7 days, the window is since admission/entry or reentry. The manual uses "7-day look-back period" (N0415H1) and "observation period"/"7-day observation period" (N0415H2, N0415 Coding Instructions) interchangeably for the same window.

## Coding rules

1. Check N0415H1 if an opioid medication was taken by the resident at any time during the 7-day look-back period (or since admission/entry or reentry if less than 7 days).[^1]
2. Check N0415H2 only if there is an indication noted for ALL opioid medications taken by the resident any time during the observation period (or since admission/entry or reentry if less than 7 days).[^2]
3. Column 2 (indication noted) is coded only if Column 1 is checked.[^3]
4. Code all high-risk drug class medications according to their pharmacological classification, not how they are being used.[^4]
5. Code medications in Item N0415 according to the medication's therapeutic category and/or pharmacological classification, not how it is used.[^5]
6. Medications with more than one therapeutic category and/or pharmacological classification are coded in all categories/classifications assigned to the medication, regardless of how it is being used.[^6]
7. Include any of these medications given to the resident by any route in any setting (e.g., at the nursing home, in a hospital emergency room) while a resident of the nursing home.[^7]
8. Code a medication even if it was given only once during the look-back period.[^8]
9. Count long-acting medications given every few weeks or monthly only if they are given during the 7-day look-back period (or since admission/entry or reentry if less than 7 days).[^9]
10. For transdermal patches, capture the medication only if the patch was applied to the resident's skin during the observation period; e.g., a fentanyl patch applied on days 1, 4, and 7 of the 7-day look-back period means N0415H Opioid would be checked.[^10]
11. Combination medications are coded in all categories/pharmacologic classes that constitute the combination.[^11]
12. Herbal and alternative medicine products are not counted as medications for this item.[^12]
13. Check N0415Z1, None of the above, if none of the listed medications (including opioids) were taken by the resident at any time during the observation period (or since admission/entry or reentry if less than 7 days).[^13]

## What the chart must show

1. Medical record documentation that the medication was received by the resident and documentation of the indication for its use during the 7-day look-back period (or since admission/entry or reentry if less than 7 days). *(importance to an auditor: high)*[^14]
   Supports both Column 1 (is taking) and Column 2 (indication noted).
2. Documentation from other health care settings where the resident may have received the medication while a resident of the nursing home (e.g., medication given in the emergency room). *(importance to an auditor: medium)*[^15]
3. The indication must be the identified, documented clinical rationale for administering the medication, based upon a physician's (or prescriber's) assessment of the resident's condition and therapeutic goals. *(importance to an auditor: high)*[^16]
   Definition box; drives whether Column 2 may be checked.
4. Assessors should be able to identify the source(s) used to support coding the pharmacological classification on the MDS 3.0 (e.g., a consistently used reference resource, manufacturer's package insert, or the pharmacist). *(importance to an auditor: low)*[^17]
   Framed as "may wish to"; use of listed resources is not required for MDS completion (p. N-12).
