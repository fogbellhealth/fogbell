## Look-back window

**7 days**[^1]

7-day look-back/observation period, or since admission/entry or reentry if less than 7 days. The N0415 item box states the window as "during the last 7 days or since admission/entry or reentry if less than 7 days" (p. N-4). ## Coding rules

1. Check N0415J1 if a hypoglycemic medication (including insulin) was taken by the resident at any time during the 7-day observation period (or since admission/entry or reentry if less than 7 days).[^1]
2. Check N0415J2 only if Column 1 is checked, and only if there is an indication noted for ALL hypoglycemic medications taken by the resident any time during the observation period.[^3]
3. Code all high-risk drug class medications according to their pharmacological classification, not how they are being used.[^4]
4. Code medications in N0415 according to the medication's therapeutic category and/or pharmacological classification, not how it is used.[^5]
5. Medications with more than one therapeutic category and/or pharmacological classification must be coded in all applicable categories/classifications, regardless of how the medication is used.[^6]
6. Include any of these medications given to the resident by any route in any setting (e.g., at the nursing home, in a hospital emergency room) while a resident of the nursing home.[^7]
7. Code a medication even if it was given only once during the look-back period.[^8]
8. Combination medications should be coded in all categories/pharmacologic classes that constitute the combination.[^9]
9. Transdermal patches: only capture the medication if the transdermal patch was applied to the resident's skin during the observation period.[^10]
10. Herbal and alternative medicine products are considered dietary supplements and should not be counted as medications.[^11]
11. Check N0415Z1, None of the above, if none of the listed medications were taken by the resident at any time during the observation period (or since admission/entry or reentry if less than 7 days).[^12]

2. Review documentation from other health care settings where the resident may have received any of these medications while a resident of the nursing home (e.g., valium given in the emergency room). *(importance to an auditor: high)*[^14]
3. The indication supporting Column 2 must be the identified, documented clinical rationale for administering the medication, based upon a physician's (or prescriber's) assessment of the resident's condition and therapeutic goals. *(importance to an auditor: high)*[^15]
   Definition box for N0415.
4. Assessors should be able to identify the source(s) used to support coding the pharmacological classification on the MDS 3.0; facilities may wish to identify a consistent resource. *(importance to an auditor: medium)*[^16]
   Framed as a suggestion ("may wish") but with an expectation that sources are identifiable.
5. Assessors may consult the manufacturer's package insert or work with the resident's pharmacist to confirm the medication classification(s). *(importance to an auditor: low)*[^17]
   Suggested resource, not a required document.
6. Providers are responsible for coding each medication's pharmacological/therapeutic classification accurately; use of the listed external reference resources is not required for MDS completion. *(importance to an auditor: low)*[^18]
