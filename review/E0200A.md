## Look-back window

**7 days**[^1]

The item's own Steps for Assessment and Coding Instructions state a 7-day look-back period ("if the behavior was exhibited 1-3 days of the last 7 days"). Per the general convention, the ARD is the last day of the observation period and the window is ARD plus the 6 previous calendar days (rai-manual-v1.20.1, p. 2-21: "ARD + 6 previous calendar days"). The section Intent also frames the items as identifying "behavioral symptoms in the last seven days" (p. E-1).

## Coding rules

1. E0200A captures physical behavioral symptoms directed toward others (e.g., hitting, kicking, pushing, scratching, grabbing, abusing others sexually); enter the frequency code in the box.[^6]
2. Code based on whether the symptoms occurred and not based on an interpretation of the behavior's meaning, cause or the assessor's judgment that the behavior can be explained or should be tolerated.[^7]
3. Code the behavior as present even if staff have become used to the behavior or view it as typical or tolerable.[^8]
4. Behaviors in these categories should be coded as present or not present, whether or not they might represent a rejection of care.[^9]
5. Resident intent must not be taken into account when coding items in Section E; the section focuses on the resident's actions, not the intent of the behavior.[^10]
6. The frequency code reflects the number of days the behavior occurred within the 7-day look-back period, not the number or severity of episodes on any given day.[^11]
7. Coding of E0200A determines downstream items: if E0200A, E0200B, and E0200C are all coded 0, code E0300 as 0 (no) and skip to E0800; if any of E0200A, E0200B, or E0200C were coded 1, 2, or 3, code E0300 as 1 (yes) and complete E0500 and E0600.[^12]
