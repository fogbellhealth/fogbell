## Coding rules

1. Code all high-risk drug class medications according to their pharmacological classification, not how they are being used.[^4]
2. Column 1: Check if the resident is taking any medications by pharmacological classification during the 7-day observation period (or since admission/entry or reentry if less than 7 days).[^5]
3. Column 2 is coded only if Column 1 is checked; check Column 2 if there is an indication noted for all medications in the drug class.[^6]
4. Code medications in Item N0415 according to the medication's therapeutic category and/or pharmacological classification, not how it is used.[^7]
5. Medications with more than one therapeutic category and/or pharmacological classification are coded in all categories/classifications assigned to the medication, regardless of how it is being used.[^8]
6. Include any of these medications given to the resident by any route in any setting (e.g., at the nursing home, in a hospital emergency room) while a resident of the nursing home.[^9]
7. Code a medication even if it was given only once during the look-back period.[^10]
8. Count long-acting medications that are given every few weeks or monthly only if they are given during the 7-day look-back period (or since admission/entry or reentry if less than 7 days).[^11]
9. For transdermal patches, only capture the medication if the transdermal patch was applied to the resident's skin during the observation period.[^12]
10. Combination medications should be coded in all categories/pharmacologic classes that constitute the combination.[^13]
11. Herbal and alternative medicine products are dietary supplements and should not be counted as medications.[^14]
12. Providers are responsible for coding each medication's pharmacological/therapeutic classification accurately; use of the listed reference resources is not required for MDS completion.[^15]

## What the chart must show

1. Review the resident's medical record for documentation that any of these medications were received by the resident and for the indication of their use during the 7-day look-back period (or since admission/entry or reentry if less than 7 days). *(importance to an auditor: high)*[^16]
   Stated as Step 1 for Assessment for N0415.
2. Review documentation from other health care settings where the resident may have received any of these medications while a resident of the nursing home (e.g., valium given in the emergency room). *(importance to an auditor: high)*[^17]
   Stated as Step 2 for Assessment for N0415.
3. An "indication" is the identified, documented clinical rationale for administering a medication that is based upon a physician's (or prescriber's) assessment of the resident's condition and therapeutic goals; Column 2 requires such an indication for all medications in the class. *(importance to an auditor: high)*[^18]
   Definition box on the same page as the coding instructions.
4. Assessors should be able to identify the source(s) used to support coding of pharmacological classification on the MDS 3.0; facilities may wish to identify a consistently used reference resource. *(importance to an auditor: medium)*[^19]
   Framed as a suggestion ("may wish") but with an expectation that the source is identifiable.
5. Assessors should consult the manufacturer's package insert for the medication's pharmacological classification and may work with the resident's pharmacist to confirm classification. *(importance to an auditor: low)*[^20]
   Suggested practice.
