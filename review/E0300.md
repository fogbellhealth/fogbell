## Coding rules

1. Code E0300 by reviewing the coding for item E0200 and following the E0300 coding instructions.[^3]
2. Code 0 (no) when E0200A, E0200B, and E0200C are all coded 0 (not present); then skip to E0800, Rejection of Care—Presence & Frequency.[^1]
3. Code 1 (yes) when any of E0200A, E0200B, or E0200C were coded 1, 2, or 3; then proceed to complete E0500 (Impact on Resident) and E0600 (Impact on Others).[^2]
4. The item asks whether any behavioral symptoms in questions E0200 were coded 1, 2, or 3; response 0 = No (skip to E0800), 1 = Yes (considering all of E0200, answer E0500 and E0600 below).[^4]
5. E0300 determines whether items E0500 (Impact on Resident) and E0600 (Impact on Others) are required to be completed.[^5]
