## Coding rules

1. Code all high-risk drug class medications according to their pharmacological classification, not how they are being used.[^4]
2. Column 1: check if the resident is taking any medications by pharmacological classification during the 7-day observation period (or since admission/entry or reentry if less than 7 days).[^5]
3. Column 2 is coded only if Column 1 is checked; then check whether there is an indication noted for all medications in the drug class.[^6]
4. Check N0415E1 if an anticoagulant medication was taken by the resident at any time during the 7-day look-back period (or since admission/entry or reentry if less than 7 days).[^1]
5. Check N0415E2 if there is an indication noted for all anticoagulant medications taken by the resident any time during the observation period (or since admission/entry or reentry if less than 7 days).[^2]
6. Do not code antiplatelet medications such as aspirin/extended release, dipyridamole, or clopidogrel as N0415E, Anticoagulant.[^7]
7. Anticoagulants such as Target Specific Oral Anticoagulants (TSOACs), which may or may not require laboratory monitoring, should be coded in N0415E, Anticoagulant.[^8]
8. Do not code flushes to keep an IV access patent in N0415E, Anticoagulant.[^9]
9. Code a medication even if it was given only once during the look-back period.[^10]
10. Include any of these medications given to the resident by any route in any setting (e.g., at the nursing home, in a hospital emergency room) while a resident of the nursing home.[^11]
11. Medications that have more than one therapeutic category and/or pharmacological classification must be coded in all categories/classifications assigned to the medication, regardless of how it is being used.[^12]
12. Combination medications should be coded in all categories/pharmacologic classes that constitute the combination.[^13]
13. Long-acting medications given every few weeks or monthly are counted only if they are given during the 7-day look-back period (or since admission/entry or reentry if less than 7 days).[^14]
14. For transdermal patches, capture the medication only if the transdermal patch was applied to the resident's skin during the observation period.[^15]
15. Herbal and alternative medicine products are dietary supplements and should not be counted as medications.[^16]
16. Code medications in Item N0415 according to the medication's therapeutic category and/or pharmacological classification, not how it is used.[^17]

## What the chart must show

1. Medical record documentation that the medication was received by the resident and documentation of the indication for its use during the 7-day look-back period (or since admission/entry or reentry if less than 7 days). *(importance to an auditor: high)*[^18]
   Step 1 of Steps for Assessment for N0415.
2. Documentation from other health care settings where the resident may have received any of these medications while a resident of the nursing home (e.g., valium given in the emergency room) must be reviewed. *(importance to an auditor: high)*[^19]
   Step 2 of Steps for Assessment for N0415.
3. The indication supporting Column 2 is the identified, documented clinical rationale for administering a medication, based upon a physician's (or prescriber's) assessment of the resident's condition and therapeutic goals. *(importance to an auditor: high)*[^20]
   Definition box, "INDICATION".
4. Assessors should be able to identify the source(s) used to support coding the pharmacological classification on the MDS 3.0; facilities may wish to identify a consistent resource for classification. *(importance to an auditor: medium)*[^21]
   Framed as a suggestion ("may wish") but includes an expectation that the source be identifiable.
5. Providers are responsible for coding each medication's pharmacological/therapeutic classification accurately; the listed reference resources are optional and not required for MDS completion. *(importance to an auditor: medium)*[^22]
