## Coding rules

1. Code based on behaviors observed and/or thoughts expressed in the last 7 days rather than the presence of a medical diagnosis; check all that apply.[^5]
2. Resident intent must not be taken into account when coding items in Section E; the section focuses on the resident's actions, not the intent of their behavior.[^6]
3. If a belief cannot be objectively shown to be false, or it is not possible to determine whether it is false, do not code it as a delusion.[^7]
4. If a resident expresses a false belief but easily accepts a reasonable alternative explanation, do not code it as a delusion; if the resident continues to insist the belief is correct despite an explanation or direct evidence to the contrary, code as a delusion.[^8]
5. A false belief that is readily altered with a simple reminder (i.e., attributable to memory loss/forgetfulness rather than psychosis) does not meet the definition of a delusion; code E0100Z.[^9]
6. Misinterpretation of a real external sound or stimulus that the resident accepts an alternative explanation for is not a fixed false belief and is not coded as a delusion (code E0100Z).[^10]
7. Both E0100A and E0100B may be checked when both a hallucination and a delusion are present.[^11]
