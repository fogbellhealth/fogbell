## Look-back window

**7 days**[^1]

The item's own pages state a 7-day observation/look-back period (or since admission/entry or reentry if less than 7 days) for both N0415K1 and N0415K2. Per the general convention on p. 2-21, the ARD is day 1 of the count, so the window is the ARD plus the 6 previous calendar days. The item pages use both the phrase '7-day observation period' (N0415K1, p. N-8) and, for the Steps for Assessment and Column 1 general instruction, '7-day look-back period'/'7-day observation period' (p. N-6); these refer to the same window.

## Coding rules

1. Check N0415K1 if an anticonvulsant medication was taken by the resident at any time during the 7-day observation period (or since admission/entry or reentry if less than 7 days).[^1]
2. Check N0415K2 only if there is an indication noted for ALL anticonvulsant medications taken by the resident any time during the observation period (or since admission/entry or reentry if less than 7 days).[^2]
3. Column 2 (indication noted) is coded only when Column 1 is checked.[^3]
4. Code all high-risk drug class medications according to their pharmacological classification, not how they are being used; Column 1 = check if the resident is taking any medications by pharmacological classification during the 7-day observation period (or since admission/entry or reentry if less than 7 days).[^4]
5. Code medications in Item N0415 according to the medication's therapeutic category and/or pharmacological classification, not how it is used.[^5]
6. Medications that have more than one therapeutic category and/or pharmacological classification must be coded in all categories/classifications assigned to the medication, regardless of how it is being used.[^6]
7. Include any of these medications given to the resident by any route in any setting (e.g., at the nursing home, in a hospital emergency room) while a resident of the nursing home.[^7]
8. Code a medication even if it was given only once during the look-back period.[^8]
9. Count long-acting medications given every few weeks or monthly only if they are given during the 7-day look-back period (or since admission/entry or reentry if less than 7 days).[^9]
10. For transdermal patches, only capture the medication if the transdermal patch was applied to the resident's skin during the observation period.[^10]
11. Combination medications must be coded in all categories/pharmacologic classes that constitute the combination.[^11]
12. Herbal and alternative medicine products (dietary supplements) are not counted as medications for this item.[^12]
13. Check N0415Z1, None of the above, if none of the listed medications (including anticonvulsants) were taken by the resident at any time during the observation period (or since admission/entry or reentry if less than 7 days).[^13]
14. Providers are responsible for coding each medication's pharmacological/therapeutic classification accurately; use of the listed reference resources is not required for MDS completion.[^14]

## What the chart must show

1. Review the resident's medical record for documentation that the medication was received by the resident and for the indication of its use during the 7-day look-back period (or since admission/entry or reentry if less than 7 days). *(importance to an auditor: high)*[^15]
   Primary source review step for both Column 1 and Column 2 coding.
2. Review documentation from other health care settings where the resident may have received any of these medications while a resident of the nursing home (e.g., valium given in the emergency room). *(importance to an auditor: high)*[^16]
3. For Column 2 (N0415K2), the indication must be an identified, documented clinical rationale for administering the medication, based upon a physician's (or prescriber's) assessment of the resident's condition and therapeutic goals. *(importance to an auditor: high)*[^17]
   Definition box on the N0415 page; establishes that the indication must be documented.
4. Assessors should be able to identify the source(s) used to support coding the MDS 3.0 pharmacological classification; facilities may wish to identify a resource their staff consistently use. *(importance to an auditor: medium)*[^18]
   Framed as a suggestion ("may wish") but with an expectation that the coding source is identifiable.
5. Assessors may consult the manufacturer's package insert for the medication's pharmacological classification, or work with the resident's pharmacist to confirm classification. *(importance to an auditor: low)*[^19]
   Suggested resource; use of resources is not required for MDS completion (p. N-12).
