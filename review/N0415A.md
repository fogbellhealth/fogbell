## Look-back window

**7 days**[^1]

7-day look-back period, or since admission/entry or reentry if less than 7 days. Per the general convention, the ARD is day 1 counting back (ARD + 6 previous calendar days). Column 1 (N0415A1) and Column 2 (N0415A2) both use the 7-day look-back/observation period.

## Coding rules

1. Code all high-risk drug class medications according to their pharmacological classification, not how they are being used.[^4]
2. Column 1: Check if the resident is taking any medications by pharmacological classification during the 7-day observation period (or since admission/entry or reentry if less than 7 days).[^5]
3. Column 2: If Column 1 is checked, check if there is an indication noted for all medications in the drug class.[^6]
4. Check N0415A1 if an antipsychotic medication was taken by the resident at any time during the 7-day look-back period (or since admission/entry or reentry if less than 7 days).[^1]
5. Check N0415A2 if there is an indication noted for all antipsychotic medications taken by the resident any time during the observation period (or since admission/entry or reentry if less than 7 days).[^2]
6. Code medications according to the medication's therapeutic category and/or pharmacological classification, not how it is used (e.g., oxazepam prescribed as a hypnotic is coded as antianxiety, not hypnotic).[^7]
7. Medications with more than one therapeutic category and/or pharmacological classification are coded in all categories/classifications assigned to the medication, regardless of how used (e.g., prochlorperazine, dually classified as antipsychotic and antiemetic, is coded as an antipsychotic).[^8]
8. Include any of these medications given to the resident by any route in any setting (e.g., at the nursing home, in a hospital emergency room) while a resident of the nursing home.[^9]
9. Code a medication even if it was given only once during the look-back period.[^10]
10. Count long-acting medications, such as fluphenazine decanoate or haloperidol decanoate, given every few weeks or monthly, only if they are given during the 7-day look-back period (or since admission/entry or reentry if less than 7 days).[^11]
11. For transdermal patches, only capture the medication if the transdermal patch was applied to the resident's skin during the observation period.[^12]
12. Combination medications are coded in all categories/pharmacologic classes that constitute the combination (e.g., a single tablet combining an antipsychotic and an antidepressant is coded in both antipsychotic and antidepressant categories).[^13]
13. Herbal and alternative medicine products are not counted as medications (e.g., melatonin, chamomile, valerian root).[^14]
14. Coding example: risperidone received PRN on 3 days for bipolar disorder with indication noted results in N0415A1 and N0415A2 Antipsychotic both checked.[^15]
15. Skip logic into N0415: if N0300 (Injections) is coded 0, skip to N0415, High-Risk Drug Classes: Use and Indication.[^16]

## What the chart must show

1. Review the resident's medical record for documentation that any of these medications were received by the resident and for the indication of their use during the 7-day look-back period (or since admission/entry or reentry if less than 7 days). *(importance to an auditor: high)*[^17]
   Step 1 for assessment.
2. Review documentation from other health care settings where the resident may have received any of these medications while a resident of the nursing home (e.g., valium given in the emergency room). *(importance to an auditor: high)*[^18]
   Step 2 for assessment.
3. An indication is the identified, documented clinical rationale for administering a medication that is based upon a physician's (or prescriber's) assessment of the resident's condition and therapeutic goals; Column 2 requires such an indication be noted for all medications in the drug class. *(importance to an auditor: high)*[^19]
   Definition box on the same page as the coding instructions.
4. Assessors should be able to identify the source(s) used to support coding the MDS 3.0 for pharmacological classification; facilities may wish to identify a consistently used resource. *(importance to an auditor: medium)*[^20]
   Framed as a suggestion ("may wish") but with an expectation that sources are identifiable.
5. Assessors may consult the manufacturer's package insert or work with the resident's pharmacist to confirm medication classification(s). *(importance to an auditor: low)*[^21]
   Suggested resource, not a required document.
6. When a resident receives antipsychotic, antianxiety, and hypnotic medications simultaneously, adequate documentation of a clear clinical indication is essential to justify their use. *(importance to an auditor: high)*[^22]
   Stated in the note following the N0415 example; the manual adds "Adequate documentation is essential in justifying their use."
