## Look-back window

**7 days**[^1]

7-day look-back period; if the resident has been in the facility less than 7 days, the window is since admission/entry or reentry. The manual uses "7-day look-back period" and "7-day observation period" interchangeably for this item (p. N-6, p. N-7). The exact method of counting days relative to the ARD is not stated on these pages.

> **Note:** the manual states more than one time period for this item. See the *Conflicts* section below.

## Coding rules

1. Check N0415A1 if an antipsychotic medication was taken by the resident at any time during the 7-day look-back period (or since admission/entry or reentry if less than 7 days).[^1]
2. Check N0415A2 only if there is an indication noted for ALL antipsychotic medications taken by the resident any time during the observation period (or since admission/entry or reentry if less than 7 days).[^2]
3. Column 2 (Indication noted) is completed only when Column 1 is checked.[^4]
4. Code all high-risk drug class medications according to their pharmacological classification, not how they are being used.[^5]
5. Code medications in Item N0415 according to the medication's therapeutic category and/or pharmacological classification, not how it is used (e.g., oxazepam prescribed as a hypnotic is coded as an antianxiety medication).[^6]
6. Medications with more than one therapeutic category and/or pharmacological classification must be coded in all assigned categories/classifications regardless of how used; e.g., prochlorperazine, dually classified as an antipsychotic and an antiemetic, is coded as an antipsychotic.[^7]
7. Combination medications are coded in all categories/pharmacologic classes that constitute the combination; e.g., a single tablet combining an antipsychotic and an antidepressant is coded in both the antipsychotic and antidepressant categories.[^8]
8. Include medications given to the resident by any route in any setting (e.g., at the nursing home, in a hospital emergency room) while a resident of the nursing home.[^9]
9. Code a medication even if it was given only once during the look-back period.[^10]
10. Count long-acting medications, such as fluphenazine decanoate or haloperidol decanoate, that are given every few weeks or monthly only if they are given during the 7-day look-back period (or since admission/entry or reentry if less than 7 days).[^11]
11. For transdermal patches, capture the medication only if the patch was applied to the resident's skin during the observation period.[^12]
12. Herbal and alternative medicine products (e.g., melatonin, chamomile, valerian root) are dietary supplements and should not be counted as medications.[^13]
13. Column 1 is checked based on medications the resident is taking by pharmacological classification during the 7-day observation period (or since admission/entry or reentry if less than 7 days).[^14]
14. Check N0415Z1, None of the above, if none of the listed medications (including antipsychotics) were taken by the resident at any time during the observation period (or since admission/entry or reentry if less than 7 days).[^15]

## What the chart must show

1. Medical record documentation that the antipsychotic medication was received by the resident and documentation of the indication for its use during the 7-day look-back period (or since admission/entry or reentry if less than 7 days). *(importance to an auditor: high)*[^16]
   Step 1 of Steps for Assessment for N0415.
2. The "indication" supporting Column 2 must be the identified, documented clinical rationale for administering the medication, based upon a physician's (or prescriber's) assessment of the resident's condition and therapeutic goals. *(importance to an auditor: high)*[^17]
   Definition box on the same page as the coding instructions.
3. Documentation from other health care settings where the resident may have received these medications while a resident of the nursing home (e.g., valium given in the emergency room) should be reviewed. *(importance to an auditor: medium)*[^18]
   Step 2 of Steps for Assessment for N0415.
4. Assessors should be able to identify the source(s) used to support coding the pharmacological classification on the MDS 3.0 (e.g., a consistently used facility resource, the manufacturer's package insert, or the pharmacist). *(importance to an auditor: medium)*[^19]
   Framed as a suggestion ("may wish to") coupled with an expectation that the source can be identified.
5. When a resident receives antipsychotic, antianxiety and hypnotic medications simultaneously there must be a clear clinical indication for their use; adequate documentation is essential in justifying their use. *(importance to an auditor: high)*[^20]
   Stated as a "Please note" following the N0415 coding example.
6. Providers are responsible for coding each medication's pharmacological/therapeutic classification accurately; the listed external resources are optional and not required for MDS completion. *(importance to an auditor: medium)*[^21]

## ⚠️ Conflicts — please read carefully

> **Wording of the look-back window for the Antipsychotic sub-items: "7-day look-back period" vs. "observation period"**
>
> - *Federal manual:* N0415A1 is described as covering the 7-day look-back period (or since admission/entry or reentry if less than 7 days).[^1]
> - *Federal manual:* N0415A2 is described as covering "the observation period" without stating 7 days, while the general coding instruction for Column 1 calls it the "7-day observation period."[^14]
>
> Status: Terminology only; the manual uses "7-day look-back period" and "7-day observation period" interchangeably for N0415, and both carry the same "or since admission/entry or reentry if less than 7 days" qualifier.
