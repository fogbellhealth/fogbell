## Look-back window

**14 days**[^1]

The observation window differs by column and is stated on the item's own pages, so the general 7-day convention does not apply. Column b (While a Resident) uses the last 14 days (and only since admission/entry or reentry). Column a (On Admission) uses days 1–3 of the SNF PPS Stay starting with A2400B. Column c (At Discharge) uses the last 3 days of the SNF PPS Stay ending with A2400C. the look-back window is set to 14 for the resident-level (column b) observation window; the two 3-day SNF PPS assessment periods are recorded here and in conflicting passages (none found).

## Coding rules

1. Code only tracheal and/or nasopharyngeal suctioning in O0110D1; do not code oral suctioning.[^6]
2. O0110D1 may be coded when the resident performs their own tracheal and/or nasopharyngeal suctioning.[^7]
3. Check O0110D2, Scheduled, if suctioning was scheduled — i.e., performed when the resident is assessed as clinically benefiting from regular interventions, such as every hour or once per shift; scheduled suctioning applies to medical orders for suctioning at specific intervals and/or implementation of facility-based clinical standards, protocols, and guidelines.[^8]
4. Check O0110D3, As needed, if suctioning was performed on an as-needed basis, as opposed to at regular scheduled intervals.[^9]
5. Facilities may code treatments, programs and procedures that the resident performed themselves independently or after set-up by facility staff.[^10]
6. Do not code services that were provided solely in conjunction with a surgical procedure or diagnostic procedure; surgical procedures include routine pre- and post-operative procedures.[^11]
7. Column a (On Admission): check the treatment if received by, performed on, or participated in by the resident on days 1–3 of the SNF PPS Stay starting with A2400B; if nothing was received or performed in the 3-day assessment period, check Z, None of the above.[^12]
8. Column b (While a Resident): check the treatment if the resident received or performed it after admission/entry or reentry to the facility and within the last 14 days; if none within the last 14 days or since admission/entry or reentry, check Z, None of the above.[^13]
9. Column c (At Discharge): check the treatment if received by, performed on, or participated in by the resident in the last 3 days of the SNF PPS Stay ending with A2400C; if none in the 3-day assessment period, check Z, None of the above.[^14]
10. Check all that apply: the O0110 checkboxes are marked only for treatments, procedures, and programs that were performed in the applicable column's assessment period.[^15]

## ⚠️ Conflicts — please read carefully

The manual (or two documents) say different things here. Both sides are shown; nothing has been dropped.

> **Coexisting observation windows for O0110D across the three columns**
>
> - *Federal manual:* Column b (While a Resident) uses a 14-day window: treatments performed while a resident of this facility and within the last 14 days.[^1]
> - *Federal manual:* Column a (On Admission) uses a 3-day window: days 1 through 3 of the SNF PPS Stay starting with A2400B.[^18]
> - *Federal manual:* Column c (At Discharge) uses a 3-day window: the last 3 days of the SNF PPS Stay ending on A2400C.[^19]
>
> Status: Resolved by the document: the Steps for Assessment instruct the assessor to use "the assessment period defined for each column" (p. O-3), so the 14-day window applies only to column b and the 3-day windows apply to columns a and c respectively.

> **Availability of the D2/D3 sub-elements in column b (While a Resident)**
>
> - *Federal manual:* The O0110 item table provides check boxes for D2 (Scheduled) and D3 (As needed) only under columns a. On Admission and c. At Discharge; no check box appears under b. While a Resident for these sub-elements, while D1 Suctioning has boxes in all three columns.[^2]
> - *Federal manual:* The narrative coding instructions for columns a, b, and c direct the assessor to check all treatments, procedures, and programs for each column without excluding the D2/D3 sub-elements from column b.[^20]
>
> Status: unresolved — surface to user
