## Coding rules

1. Consider all of the symptoms assessed in items E0100 through E1000 when coding E1100.[^5]
2. Code how the resident's current behavior status, care rejection, or wandering compares to the prior assessment (OBRA or Scheduled PPS).[^6]
3. Review responses provided to items E0100-E1000 on the current MDS assessment and compare with responses provided on the prior MDS assessment.[^7]
4. Taking all of these MDS items into consideration, make a global assessment of the change in behavior from the most recent to the current MDS, and rate the overall behavior as same, improved, or worse.[^8]
5. When a resident has multiple behavioral symptoms that vary in different directions, use clinical judgment to rate the item to reflect the overall direction of behavior change, estimating the net effects of multiple behaviors.[^9]
6. E1100 is the item reached when E0900 Wandering—Presence & Frequency is coded 0, behavior not exhibited (skip to Change in Behavior or Other Symptoms item E1100).[^10]

## What the chart must show

1. Responses to items E0100-E1000 on the current MDS assessment (the assessment record itself) must be available for review. *(importance to an auditor: high)*[^11]
   Stated as step 1 of Steps for Assessment.
2. The prior MDS assessment responses must be available for comparison; if no prior MDS assessment exists, code 3, N/A. *(importance to an auditor: high)*[^12]
   Absence of a prior MDS assessment drives code 3.
