## Coding rules

1. Check N0415D1 if a hypnotic medication was taken by the resident at any time during the 7-day look-back period (or since admission/entry or reentry if less than 7 days).[^1]
2. Check N0415D2 only if there is an indication noted for ALL hypnotic medications taken by the resident any time during the observation period (or since admission/entry or reentry if less than 7 days).[^2]
3. Column 2 (indication noted) is coded only if Column 1 is checked.[^4]
4. Code all high-risk drug class medications according to their pharmacological classification, not how they are being used.[^5]
5. Code medications in N0415 by therapeutic category and/or pharmacological classification, not by use; e.g., oxazepam prescribed as a hypnotic is coded as antianxiety, not as a hypnotic.[^6]
6. Over-the-counter sleeping medications are not coded as hypnotics because they are not categorized as hypnotic medications.[^7]
7. Herbal and alternative medicine products (e.g., melatonin, chamomile, valerian root) are not counted as medications for this item.[^8]
8. Code a medication even if it was given only once during the look-back period.[^9]
9. Include any of these medications given to the resident by any route in any setting (e.g., at the nursing home, in a hospital emergency room) while a resident of the nursing home.[^10]
10. Medications with more than one therapeutic category and/or pharmacological classification must be coded in all assigned categories/classifications, regardless of how the medication is being used.[^11]
11. Combination medications are coded in all categories/pharmacologic classes that constitute the combination.[^12]
12. Long-acting medications given every few weeks or monthly are counted only if they are given during the 7-day look-back period (or since admission/entry or reentry if less than 7 days).[^13]
13. For transdermal patches, capture the medication for N0415 only if the patch was applied to the resident's skin during the observation period.[^14]
14. A hypnotic taken PRN during the look-back period is checked in N0415D1; N0415D2 is left unchecked when the indication for its use was not noted (example: temazepam given PRN with no indication documented).[^15]

## What the chart must show

1. Medical record documentation that the medication was received by the resident and documentation of the indication for its use during the 7-day look-back period (or since admission/entry or reentry if less than 7 days). *(importance to an auditor: high)*[^16]
   Steps for Assessment step 1 for N0415.
2. Review documentation from other health care settings where the resident may have received any of these medications while a resident of the nursing home (e.g., valium given in the emergency room). *(importance to an auditor: high)*[^17]
   Steps for Assessment step 2 for N0415.
3. The indication must be an identified, documented clinical rationale for administering the medication, based upon a physician's (or prescriber's) assessment of the resident's condition and therapeutic goals. *(importance to an auditor: high)*[^18]
   DEFINITIONS box: INDICATION. Supports coding of Column 2 (N0415D2).
4. Assessors should be able to identify the source(s) used to support coding the MDS 3.0 pharmacological classification (facilities may identify a consistent classification resource; the package insert or the resident's pharmacist may be consulted). *(importance to an auditor: medium)*[^19]
   Framed as a suggestion ("may wish to") with an expectation that assessors can identify the source used.
5. When a resident receives antipsychotic, antianxiety and hypnotic medications simultaneously there must be a clear clinical indication for their use; adequate documentation is essential in justifying their use. *(importance to an auditor: high)*[^20]
   Same page adds: "Adequate documentation is essential in justifying their use."
6. Providers are responsible for coding each medication's pharmacological/therapeutic classification accurately; use of the listed reference resources is not required for MDS completion. *(importance to an auditor: medium)*[^21]
