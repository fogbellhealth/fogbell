## Look-back window

**7 days**[^1]

7-day look-back period, or since admission/entry or reentry if the stay is less than 7 days. The same 7-day window applies to both N0350A (insulin injections received) and N0350B (insulin order changes). The document does not state how the 7 days are counted relative to the ARD on these pages.

## Coding rules

1. Enter in Item N0350A the number of days during the 7-day look-back period (or since admission/entry or reentry if less than 7 days) that insulin injections were received.[^1]
2. Enter in Item N0350B the number of days during the 7-day look-back period (or since admission/entry or reentry if less than 7 days) that the physician (nurse practitioner, physician assistant, or clinical nurse specialist if allowable under state licensure laws) changed the resident's insulin orders.[^4]
3. For sliding scale orders: a sliding scale dosage schedule written to cover different dosages depending on lab values does not count as an order change simply because a different dose is administered based on the sliding scale guidelines.[^5]
4. If the sliding scale order is new, discontinued, or is the first sliding scale order for the resident, those days can be counted and coded (as an order change).[^6]
5. For subcutaneous insulin pumps, code only the number of days that the resident actually required a subcutaneous injection to restart the pump.[^7]
6. Insulin injections are counted in Item N0350 as well as in Item N0300 (Injections).[^8]

## What the chart must show

1. Resident's medication administration records for the 7-day look-back period (or since admission/entry or reentry if less than 7 days) are reviewed to determine insulin injections received. *(importance to an auditor: high)*[^9]
   Stated as step 1 of Steps for Assessment.
2. Determination that the physician (or nurse practitioner, physician assistant, or clinical nurse specialist if allowable under state licensure laws) changed the resident's insulin orders during the look-back period. *(importance to an auditor: high)*[^10]
   Stated as step 3 of Steps for Assessment; supports coding of N0350B.
