## Look-back window

**7 days**[^1]

7-day look-back period, or since admission/entry or reentry if less than 7 days, for both N0350A and N0350B. Per the general convention (p. 2-21), a 7-day observation period consists of the ARD plus the 6 previous calendar days; the item's own pages state only "7-day look-back period."

## Coding rules

1. Enter in Item N0350A the number of days during the 7-day look-back period (or since admission/entry or reentry if less than 7 days) that insulin injections were received.[^1]
2. Enter in Item N0350B the number of days during the 7-day look-back period (or since admission/entry or reentry if less than 7 days) that the physician (nurse practitioner, physician assistant, or clinical nurse specialist if allowable under state licensure laws) changed the resident's insulin orders.[^4]
3. A sliding scale dosage schedule written to cover different dosages depending on lab values does not count as an order change simply because a different dose is administered based on the sliding scale guidelines.[^5]
4. If the sliding scale order is new, discontinued, or is the first sliding scale order for the resident, these days can be counted and coded.[^6]
5. For subcutaneous insulin pumps, code only the number of days that the resident actually required a subcutaneous injection to restart the pump.[^7]
6. Insulin injections are counted in Item N0350 as well as in Item N0300 (Injections).[^8]
