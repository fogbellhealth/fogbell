## Coding rules

1. Check E0100Z (none of the above) if no hallucinations or delusions were present in the last 7 days.[^2]
2. Code E0100 based on behaviors observed and/or thoughts expressed in the last 7 days rather than the presence of a medical diagnosis; check all that apply.[^1]
3. If a belief cannot be objectively shown to be false, or it is not possible to determine whether it is false, do not code it as a delusion (and therefore it does not support checking E0100B).[^4]
4. If a resident expresses a false belief but easily accepts a reasonable alternative explanation, do not code it as a delusion; if the resident continues to insist the belief is correct despite an explanation or direct evidence to the contrary, code as a delusion.[^5]
5. Resident intent should not be taken into account when coding items in Section E.[^6]
6. Example: a resident who reports hearing a gunshot that was actually a loud knock and who accepts the alternative interpretation is coded E0100Z (misinterpretation of a real external stimulus is not a hallucination or a fixed false belief).[^7]
7. Example: a false belief that is readily altered with a simple reminder (attributable to memory loss rather than psychosis) is coded E0100Z because it does not meet the definition of a delusion.[^8]
