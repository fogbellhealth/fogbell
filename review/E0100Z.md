## Coding rules

1. E0100 is a "check all that apply" item; check E0100Z (none of the above) if no hallucinations or delusions were present in the last 7 days.[^2]
2. Code based on behaviors observed and/or thoughts expressed in the last 7 days rather than the presence of a medical diagnosis.[^3]
3. If a belief cannot be objectively shown to be false, or it is not possible to determine whether it is false, do not code it as a delusion (and therefore it does not count toward checking E0100B, supporting E0100Z when no other indicators are present).[^4]
4. If a resident expresses a false belief but easily accepts a reasonable alternative explanation, do not code it as a delusion; if the resident continues to insist the belief is correct despite an explanation or direct evidence to the contrary, code as a delusion.[^5]
5. Resident intent must not be taken into account when coding items in Section E; the section focuses on the resident's actions, not the intent of their behavior.[^6]
6. Example: a resident who misinterprets a real external sound and accepts the alternative explanation is not delusional — E0100Z would be checked.[^7]
7. Example: a false belief readily altered with a simple reminder (attributable to memory loss rather than psychosis) is not a delusion — E0100Z would be checked.[^8]

   Step 3 in Steps for Assessment.

   Step 4 in Steps for Assessment; supports a determination that no delusion was present.
