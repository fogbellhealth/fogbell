## Look-back window

**7 days**[^1]

7-day look-back/observation period, or since admission/entry or reentry if the stay is less than 7 days. The manual uses the phrases "7-day look-back period" (e.g., N0415A1, B1, C1, D1, E1, F1, G1, H1) and "7-day observation period" (e.g., N0415I1, J1, K1) interchangeably for the same 7-day window; the Column 2 indication sub-items refer to "the observation period (or since admission/entry or reentry if less than 7 days)." The document does not state how the 7 days are counted relative to the ARD within this section.

> **Note:** the manual states more than one time period for this item. See the *Conflicts* section below.

## Coding rules

1. Code all high-risk drug class medications according to their pharmacological classification, not how they are being used.[^27]
2. Column 2 (Indication noted) is checked only if Column 1 is checked, and only if there is an indication noted for all medications in that drug class.[^28]
3. Code medications according to the medication's therapeutic category and/or pharmacological classification, not how it is used (e.g., oxazepam prescribed as a hypnotic is coded as an antianxiety medication, not a hypnotic).[^29]
4. Medications with more than one therapeutic category and/or pharmacological classification must be coded in all categories/classifications assigned to the medication, regardless of how it is being used (e.g., prochlorperazine is coded as an antipsychotic).[^30]
5. Include any of these medications given to the resident by any route in any setting (e.g., at the nursing home, in a hospital emergency room) while a resident of the nursing home.[^31]
6. Do not code antiplatelet medications such as aspirin/extended release, dipyridamole, or clopidogrel as N0415E, Anticoagulant.[^32]
7. Anticoagulants such as Target Specific Oral Anticoagulants (TSOACs), which may or may not require laboratory monitoring, should be coded in N0415E, Anticoagulant.[^33]
8. Do not code flushes to keep an IV access patent in N0415E, Anticoagulant.[^34]
9. Code a medication even if it was given only once during the look-back period.[^35]
10. Count long-acting medications (e.g., fluphenazine decanoate or haloperidol decanoate) given every few weeks or monthly only if they are given during the 7-day look-back period (or since admission/entry or reentry if less than 7 days).[^36]
11. For transdermal patches, capture the medication only if the patch was applied to the resident's skin during the observation period.[^37]
12. Combination medications should be coded in all categories/pharmacologic classes that constitute the combination (e.g., a single tablet combining an antipsychotic and an antidepressant is coded in both categories).[^38]
13. Over-the-counter sleeping medications are not coded as hypnotics, as they are not categorized as hypnotic medications.[^39]
14. Herbal and alternative medicine products (e.g., melatonin, chamomile, valerian root) are dietary supplements and should not be counted as medications.[^40]
15. When N0300 (Injections) is coded 0, skip to N0415, High-Risk Drug Classes: Use and Indication.[^41]
16. Example application: a PRN antipsychotic received with a documented indication is coded in both Column 1 and Column 2; a hypnotic received without a noted indication is coded in Column 1 only (Column 2 not checked).[^42]

## What the chart must show

1. Review the resident's medical record for documentation that any of these medications were received by the resident and for the indication of their use during the 7-day look-back period (or since admission/entry or reentry if less than 7 days). *(importance to an auditor: high)*[^43]
   Step 1 of Steps for Assessment.
2. Review documentation from other health care settings where the resident may have received any of these medications while a resident of the nursing home (e.g., valium given in the emergency room). *(importance to an auditor: high)*[^44]
   Step 2 of Steps for Assessment.
3. An "indication" is the identified, documented clinical rationale for administering a medication, based upon a physician's (or prescriber's) assessment of the resident's condition and therapeutic goals. *(importance to an auditor: high)*[^45]
   Definition box; governs whether Column 2 can be checked.
4. Assessors should be able to identify the source(s) used to support coding of pharmacological classification on the MDS 3.0; facilities may wish to identify a resource their staff consistently use. *(importance to an auditor: medium)*[^46]
   Framed as a suggestion ("may wish") but with an expectation that the source can be identified.
5. Assessors should consult the manufacturer's package insert for pharmacological classification and may work with the resident's pharmacist to confirm medication classification(s). *(importance to an auditor: low)*[^47]
   Suggested source of verification.
6. When a resident receives antipsychotic, antianxiety and hypnotic medications simultaneously there must be a clear clinical indication; adequate documentation is essential in justifying their use. *(importance to an auditor: high)*[^48]
   Stated in a note following the coding example.
7. Providers are responsible for coding each medication's pharmacological/therapeutic classification accurately; the listed external resources are optional and not required for MDS completion. *(importance to an auditor: medium)*[^49]
