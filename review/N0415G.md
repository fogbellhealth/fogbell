## Look-back window

**7 days**[^1]

7-day look-back period, or since admission/entry or reentry if less than 7 days. The manual uses "7-day look-back period" (N0415G1, p. N-7) and "observation period (or since admission/entry or reentry if less than 7 days)" (N0415G2, p. N-8) interchangeably; the item table on p. N-4 states "during the last 7 days or since admission/entry or reentry if less than 7 days." The document does not state how the window is counted relative to the ARD on these pages.

> **Note:** the manual states more than one time period for this item. See the *Conflicts* section below.

## Coding rules

1. Column 2 (Indication noted) is coded only if Column 1 is checked: if Column 1 is checked, check whether an indication is noted for all medications in the drug class.[^4]
2. Code all high-risk drug class medications according to their pharmacological classification, not how they are being used; Column 1 is checked if the resident is taking any medications by pharmacological classification during the 7-day observation period (or since admission/entry or reentry if less than 7 days).[^5]
3. Code medications in Item N0415 according to the medication's therapeutic category and/or pharmacological classification, not how it is used.[^6]
4. Medications with more than one therapeutic category and/or pharmacological classification are coded in all categories/classifications assigned to the medication, regardless of how it is being used.[^7]
5. Include any of these medications given to the resident by any route in any setting (e.g., at the nursing home, in a hospital emergency room) while a resident of the nursing home.[^8]
6. Code a medication even if it was given only once during the look-back period.[^9]
7. Long-acting medications given every few weeks or monthly are counted only if they are given during the 7-day look-back period (or since admission/entry or reentry if less than 7 days).[^10]
8. For transdermal patches, capture the medication only if the transdermal patch was applied to the resident's skin during the observation period.[^11]
9. Combination medications are coded in all categories/pharmacologic classes that constitute the combination.[^12]
10. Herbal and alternative medicine products are dietary supplements and should not be counted as medications.[^13]
11. Providers are responsible for coding each medication's pharmacological/therapeutic classification accurately; use of the listed reference resources is not required for MDS completion.[^14]

## What the chart must show

1. Medical record documentation that the medication was received by the resident and documentation of the indication for its use during the 7-day look-back period (or since admission/entry or reentry if less than 7 days). *(importance to an auditor: high)*[^15]
   Step 1 of Steps for Assessment for N0415.
2. Review documentation from other health care settings where the resident may have received any of these medications while a resident of the nursing home (e.g., medication given in the emergency room). *(importance to an auditor: high)*[^16]
   Step 2 of Steps for Assessment for N0415.
3. The indication must be the identified, documented clinical rationale for administering the medication, based on the prescriber's assessment of the resident's condition and therapeutic goals. *(importance to an auditor: high)*[^17]
   Definition box supporting Column 2 coding.
4. Assessors should be able to identify the source(s) used to support coding the MDS 3.0 for pharmacological classification; facilities may wish to identify a consistently used resource. *(importance to an auditor: medium)*[^18]
   Framed as a suggestion ("may wish") but states assessors should be able to identify the source used.
5. Assessors may consult the manufacturer's package insert or work with the resident's pharmacist to confirm medication classification(s). *(importance to an auditor: low)*[^19]
   Suggested resource, not a required record.

## ⚠️ Conflicts — please read carefully

The manual (or two documents) say different things here. Both sides are shown; nothing has been dropped.

> **Wording of the window for the Column 2 (indication noted) sub-item: "7-day look-back period" vs. "observation period"**
>
> - *Federal manual:* N0415G1 states the window as the 7-day look-back period (or since admission/entry or reentry if less than 7 days).[^1]
> - *Federal manual:* N0415G2 states the window as "the observation period (or since admission/entry or reentry if less than 7 days)" without repeating the 7-day figure.[^2]
>
> Status: Resolved by the document: the general Coding Instructions define the observation period as 7 days — "Check if the resident is taking any medications by pharmacological classification during the 7-day observation period (or since admission/entry or reentry if less than 7 days)" (p. N-6).

> **Verb used for the diuretic indication sub-item: "received by" vs. "taken by" the resident**
>
> - *Federal manual:* N0415G2 uses "received by the resident", unlike the other N0415 Column 2 sub-items.[^20]
> - *Federal manual:* Parallel Column 2 sub-items (e.g., N0415H2 Opioid) use "taken by the resident".[^21]
>
