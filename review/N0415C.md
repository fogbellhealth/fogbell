## Look-back window

**7 days**[^1]

7-day look-back period (or since admission/entry or reentry if less than 7 days) for both Column 1 (N0415C1) and Column 2 (N0415C2). Per the general convention, the look-back window is the ARD plus the 6 previous calendar days (rai-manual-v1.20.1, p. 2-17: "ARD + 6 previous calendar days"). The item's own pages state the 7-day window explicitly.

## Coding rules

1. Column 1 (N0415C1): Check if the resident is taking an antidepressant by pharmacological classification during the 7-day observation period (or since admission/entry or reentry if less than 7 days).[^4]
2. Column 2 (N0415C2): If Column 1 is checked, check if there is an indication noted for all medications in the drug class.[^5]
3. Code all high-risk drug class medications according to their pharmacological classification, not how they are being used.[^6]
4. Code medications in Item N0415 according to the medication's therapeutic category and/or pharmacological classification, not how it is used (e.g., oxazepam prescribed as a hypnotic is coded as antianxiety).[^7]
5. Medications with more than one therapeutic category and/or pharmacological classification must be coded in all categories/classifications assigned to the medication, regardless of how it is being used.[^8]
6. Combination medications are coded in all categories/pharmacologic classes that constitute the combination; e.g., a single tablet combining an antipsychotic and an antidepressant is coded in both the antipsychotic and antidepressant categories.[^9]
7. Include any of these medications given to the resident by any route in any setting (e.g., at the nursing home, in a hospital emergency room) while a resident of the nursing home.[^10]
8. Code a medication even if it was given only once during the look-back period.[^11]
9. Long-acting medications given every few weeks or monthly are counted only if they are given during the 7-day look-back period (or since admission/entry or reentry if less than 7 days).[^12]
10. For transdermal patches, only capture the medication if the transdermal patch was applied to the resident's skin during the observation period.[^13]
11. Herbal and alternative medicine products are dietary supplements and should not be counted as medications (e.g., melatonin, chamomile, valerian root).[^14]
12. N0415Z1 (None of the above) is checked if none of the listed medications, including antidepressants, were taken by the resident at any time during the observation period (or since admission/entry or reentry if less than 7 days).[^15]
13. Providers are responsible for coding each medication's pharmacological/therapeutic classification accurately; use of the listed external resources is not required for MDS completion.[^16]
14. N0415 is reached from N0300 when N0300 is coded 0 (skip pattern: If 0 → Skip to N0415, High-Risk Drug Classes: Use and Indication).[^17]

> **Wording of the Column 1 observation window for antidepressant ("7-day look-back period" vs. "7-day observation period")**
>
> - *Federal manual:* N0415C1 uses the phrase "7-day look-back period (or since admission/entry or reentry if less than 7 days)."[^1]
> - *Federal manual:* The general N0415 coding instruction for Column 1 uses the phrase "7-day observation period (or since admission/entry or reentry if less than 7 days)."[^4]
>
> Status: Terminology difference only; both describe the same 7-day window. No substantive conflict.
