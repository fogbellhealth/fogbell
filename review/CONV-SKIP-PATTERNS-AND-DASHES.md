## Coding rules

1. The standard look-back period for the MDS 3.0 is 7 days, unless otherwise stated.[^1]
2. With the exception of certain items (e.g., some items in Sections J, K and O), the look-back period does not extend into the preadmission period unless the item instructions state otherwise; in the case of reentry, the look-back period does not extend into time prior to the reentry, unless instructions state otherwise.[^6]
3. When determining the response to items with a look-back period relating back to the Admission/Entry, Reentry, or Prior OBRA or scheduled PPS assessment, whichever is most recent, staff must only consider assessments required to be submitted to iQIES; PPS assessments completed for private insurance and Medicare Advantage Plans must not be submitted to iQIES and should not be considered when determining the "prior assessment."[^7]
4. Scoring on one item may govern how scoring is completed for one or more additional items (a skip pattern); when a skip pattern is encountered, leave the item blank and move on to the next item as directed.[^8]
5. Skip pattern example: if B0100, Comatose, is answered code 1, yes, the assessor skips to item GG0100, Prior Functioning: Everyday Activities, and the intervening items from B0200–F0800 are not coded (left blank); if B0100 is answered code 0, no, the assessor continues coding at B0200, Hearing.[^9]
6. Use a check mark for boxes where the instructions state to "check all that apply," if the specified condition is met; otherwise leave those boxes blank.[^10]
7. Use a numeric response (a number or pre-assigned value) for blank boxes.[^3]
8. When recording month, day, and year for dates, enter two digits for the month and the day and four digits for the year (e.g., January 3, 2020 recorded as 01 03 2020).[^11]
9. Almost all MDS 3.0 items allow a dash (-) value to be entered and submitted to iQIES; a dash indicates the item was not assessed.[^12]
10. Dash values allow a partial assessment to be submitted when an assessment is required for payment purposes.[^13]
11. One date item (A2400C) uses a dash-filled value to indicate the event has not yet occurred (e.g., an ongoing Medicare stay where the end date has not occurred).[^14]
12. A few items do not allow dash values, including identification items in Section A (e.g., A0500 Legal Name of Resident, A2300 Assessment Reference Date, A0310 Type of Assessment, A0810 Sex) and ICD diagnosis codes (I8000); the complete list is on the CMS MDS 3.0 Technical Information web page.[^15]
13. When the term "physician" is used in this manual, it should be interpreted as including nurse practitioners, physician assistants, or clinical nurse specialists, if allowable under state licensure laws and Medicare.[^16]
