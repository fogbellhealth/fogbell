## Coding rules

1. E0200B captures verbal behavioral symptoms directed toward others (e.g., threatening others, screaming at others, cursing at others); enter a frequency code in the box.[^6]
2. Code based on whether the symptoms occurred and not based on an interpretation of the behavior's meaning, cause or the assessor's judgment that the behavior can be explained or should be tolerated.[^7]
3. Code as present, even if staff have become used to the behavior or view it as typical or tolerable.[^8]
4. Behaviors in these categories should be coded as present or not present, whether or not they might represent a rejection of care.[^9]
5. Resident intent should not be taken into account when coding items in Section E; the section focuses on the resident's actions, not the intent of their behavior.[^10]
6. The coding of E0200B (with E0200A and E0200C) drives E0300: code E0300 as 0 (no) if E0200A, E0200B, and E0200C are all coded 0; code E0300 as 1 (yes) if any of E0200A, E0200B, or E0200C were coded 1, 2, or 3, then complete E0500 and E0600.[^11]
