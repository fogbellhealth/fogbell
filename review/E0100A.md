## Coding rules

1. Code based on behaviors observed and/or thoughts expressed in the last 7 days rather than the presence of a medical diagnosis; check all that apply.[^4]
2. Check E0100A (hallucinations) if hallucinations were present in the last 7 days.[^5]
3. Resident intent is not taken into account when coding items in Section E; code the resident's actions, not the intent of their behavior.[^6]
4. A report that reflects misinterpretation of a real external sound/stimulus is not coded as a hallucination (E0100Z checked instead).[^7]
5. Reported auditory and visual sensations occurring in the absence of any external stimulus are coded as a hallucination (E0100A checked).[^8]
