## Coding rules

1. E0200C captures other behavioral symptoms not directed toward others (e.g., physical symptoms such as hitting or scratching self, pacing, rummaging, public sexual acts, disrobing in public, throwing or smearing food or bodily wastes, or verbal/vocal symptoms like screaming, disruptive sounds); enter the frequency code in the box.[^6]
2. Code based on whether the symptoms occurred and not based on an interpretation of the behavior's meaning, cause or the assessor's judgment that the behavior can be explained or should be tolerated.[^7]
3. Code as present, even if staff have become used to the behavior or view it as typical or tolerable.[^8]
4. Behaviors in these categories should be coded as present or not present, whether or not they might represent a rejection of care.[^9]
5. Item E0200C does not include wandering.[^10]
6. Resident intent must not be taken into account when coding items in Section E; the section focuses on the resident's actions, not the intent of their behavior.[^11]
7. If the behavior did not occur during the look-back period, code 0, behavior not exhibited (e.g., rummaging through a roommate's dresser drawer not observed or reported in the last 7 days).[^12]
8. E0200C coding feeds E0300: code E0300 0 (no) if E0200A, E0200B, and E0200C all are coded 0; code E0300 1 (yes) if any of E0200A, E0200B, or E0200C were coded 1, 2, or 3.[^13]
