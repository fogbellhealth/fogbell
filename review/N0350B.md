## Coding rules

1. Enter in Item N0350B the number of days during the 7-day look-back period (or since admission/entry or reentry if less than 7 days) that the physician changed the resident's insulin orders.[^1]
2. Order changes made by a nurse practitioner, physician assistant, or clinical nurse specialist count only if allowable under state licensure laws.[^2]
3. A sliding scale dosage schedule written to cover different dosages depending on lab values does not count as an order change simply because a different dose is administered based on the sliding scale guidelines.[^3]
4. If the sliding scale order is new, discontinued, or is the first sliding scale order for the resident, these days can be counted and coded.[^4]
5. For subcutaneous insulin pumps, code only the number of days that the resident actually required a subcutaneous injection to restart the pump (stated in the Coding Tips and Special Populations following the N0350B coding instructions).[^5]
6. Item wording as printed on the MDS item set: record the number of days the physician (or authorized assistant or practitioner) changed the resident's insulin orders during the last 7 days or since admission/entry or reentry if less than 7 days.[^6]
