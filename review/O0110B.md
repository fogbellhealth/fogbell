## Look-back window

**14 days**[^1]

O0110 (including B1, Radiation) has three columns, each with its own assessment period. The assessor observation window recorded here (14 days) is the one for Column b, While a Resident: "Performed while a resident of this facility and within the last 14 days" (p. O-1), reinforced by the Item Rationale reference to "the 14-day look-back period" (p. O-2). Other stated windows for this item: Column a, On Admission = "days 1 through 3 of the SNF PPS Stay starting with A2400B" (p. O-1, p. O-3); Column c, At Discharge = "the last 3 days of the SNF PPS Stay ending on A2400C" (p. O-1, p. O-3). The item's own pages state these windows, so the general 7-day convention does not apply.

## Coding rules

1. Code intermittent radiation therapy in item O0110B1.[^5]
2. Code radiation administered via radiation implant in item O0110B1.[^5]
3. Facilities may code treatments, programs and procedures that the resident performed themselves independently or after set-up by facility staff.[^6]
4. Do not code services that were provided solely in conjunction with a surgical procedure or diagnostic procedure; surgical procedures include routine pre- and post-operative procedures.[^7]
5. Column a (On Admission): check radiation if received by, performed on, or participated in by the resident on days 1–3 of the SNF PPS Stay starting with A2400B; if none were received or performed in the 3-day assessment period, check Z, None of the above.[^8]
6. Column b (While a Resident): check radiation if received or performed after admission/entry or reentry to the facility and within the last 14 days; if none within the last 14 days or since admission/entry or reentry, check Z, None of the above.[^9]
7. Column c (At Discharge): check radiation if received by, performed on, or participated in by the resident in the last 3 days of the SNF PPS Stay ending with A2400C; if none in that 3-day assessment period, check Z, None of the above.[^3]
8. Where radiation is received during the first three days of the SNF PPS stay and while a resident, check both O0110B1a (On Admission) and O0110B1b (While a Resident).[^10]

> - *Federal manual:* Column b, While a Resident, uses a 14-day window: performed while a resident of this facility and within the last 14 days.[^12]
> - *Federal manual:* Column a, On Admission, uses a 3-day window (days 1 through 3 of the SNF PPS Stay starting with A2400B), and Column c, At Discharge, uses the last 3 days of the SNF PPS Stay ending on A2400C.[^13]
> - *Federal manual:* Item Rationale describes the item as reviewed over a 14-day look-back period.[^14]
>
> Status: Not a contradiction: the document itself assigns a different assessment period to each column (p. O-3). Recorded so both windows are preserved; 14 days is used as the item's primary observation window (Column b).
