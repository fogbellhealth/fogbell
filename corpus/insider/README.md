# corpus/insider

Materials supplied by the Verifier (state audit letters, internal training decks, worked examples, corrective-action plans).
These may be non-public. The whole `corpus/` tree is git-ignored; record each file in `../MANIFEST.md` (Insider section) with its sha256 so provenance survives even though the bytes are not in git.

Nothing here may contain real resident data. If a supplied document does, redact before it enters this directory and note the redaction in the manifest.
